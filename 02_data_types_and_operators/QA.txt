1. What are the seven basic types

1 byte = 8 bits

char -> 1 byte
wchar_t (wide character) -> 2 bytes (on windows), 4 bytes on macOS and Linux
int (long, short) -> 4 bytes
float -> 4 bytes
double -> 8 bytes
bool -> 1 byte
void

2. What's the difference between signed and unsigned integers

signed -> both postive and negative
unsigned -> positive (will have 1 more bit to use)

3. Can a char variable be used like a little integer
- Yes it can hold other values than just the ASCII character set.
Typically range from -128 to 127
